> 查看题解时注意到`WHERE EXISTS/NOT EXISTS ()`语法，此处进行简单记录。

`WHERE EXISTS` 和 `WHERE NOT EXISTS` 是用于检查子查询是否返回行（记录）的条件运算符，只关心“有没有数据”（返回布尔值`TRUE`或`FALSE`），不在乎具体返回了什么内容，因此子查询的`SELECT`后写字段名、`*`、常量都可以，通常固定写`SELECT 1`。

执行时，数据库对外部查询每一行数据代入到`EXISTS`子查询，一旦找到第一条匹配的记录，立即返回`TRUE`(具有短路特性，因此效率极高)。

以下代码片段演示其基本用法。
```sql
-- 找出下单过的用户
SELECT customer_id, name 
FROM customers c
WHERE EXISTS (
    SELECT 1 
    FROM orders o 
    WHERE o.customer_id = c.customer_id
);
-- 子查询返回第1行外部条件立即成立

-- 找出未下单的用户
SELECT customer_id, name 
FROM customers c
WHERE NOT EXISTS (
    SELECT 1 
    FROM orders o 
    WHERE o.customer_id = c.customer_id
);
-- 当子查询确实无返回数据时，外部条件才成立
```

> 若场景合适应尽可能用`EXISTS/NOT EXISTS`替代`IN/NOT IN`。
>
> `NOT IN`存在陷阱，若子查询结果中包含`NULL`，整个`NOT IN`条件永远返回`FALSE`(`Unknown`)，导致主查询什么都查不到。
>
> 优化器通常能把`NOT EXISTS`优化成反连接(Anti-Join)，大数据场景下性能更优。
