> 当面临要找出某组第一行数据的场景时，优先考虑使用`row_number() / dense_rank() / rank()`等类似操作，而不是频繁调用`first_value() / nth_value()`类型的方法。

```sql
-- 优先
SELECT
    a,
    b,
    c
FROM (
    SELECT
        a,
        b,
        c,
        row_number() OVER (PARTITON BY x ORDER BY y, z) AS rn
    FROM t
)
WHERE rn = 1

-- 避免
SELECT
    first_value(a) AS a,
    first_value(b) AS b,
    first_value(c) AS c
FROM t
WINDOW w AS (PARTITON BY x ORDER BY y, z ROWS BETWEEN UNBOUNDED PRECEDING AND UNBOUNDED FOLLOWING)
```
