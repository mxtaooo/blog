本组题目主要还是对已掌握知识的回顾和训练。

在找出最常见课程组合题目中，在结果排序上遇到了问题。
实际执行的SQL是`ORDER BY transition_count DESC, first_course ASC, second_course ASC`，但得到的结果实际不正确，如下所示。
```
-- 期望
| first_course       | second_course      | transition_count |
| ------------------ | ------------------ | ---------------- |
| Advanced Python    | Docker             | 1                |
| API Design         | Cloud Architecture | 1                |
| AWS Fundamentals   | Database Design    | 1                |
| AWS Fundamentals   | Docker             | 1                |
| ...

-- 实际
| first_course       | second_course      | transition_count |
| ------------------ | ------------------ | ---------------- |
| API Design         | Cloud Architecture | 1                |
| AWS Fundamentals   | Database Design    | 1                |
| AWS Fundamentals   | Docker             | 1                |
| Advanced Python    | Docker             | 1                |
| ...
```
PostgreSQL字符串排序规则（collation）把大小写/字符权重按照ASCII的规则排序，而不是“自然字典序”。ASCII中大写字母排序比小写靠前，因此出现如上行为，此时可以强制`ORDER BY transition_count DESC, first_course COLLATE "en_US.UTF-8", second_course COLLATE "en_US.UTF-8"`指定按照英文语言排序，也可以直接将字符串按小写排序，`ORDER BY transition_count DESC, LOWER(first_course), LOWER(second_course)`。
