### 基本情形 - 限制交易次数为k

设计动态规划解题策略，首先考虑状态变量，已知存在：当前天数、交易次数、是否持仓几个变量。根据是否持仓，定义以下状态：

```
buy[i][j]: 至第i天结束、至多进行j次交易、手中持有股票的最大收益
sell[i][j]: 至第i天结束、至多进行j次交易、手中不持有股票的最大收益
```

那么初始化起始状态。
至第一天结束(`i=0`)，强制持仓状态，无论交易上限时多少，`buy[0][j] = -prices[0]`；同理，强制空仓状态，`sell[0][j] = 0`。
对任意某天，交易不超0次，强制持仓状态时`buy[i][0] = max(buy[i-1][0], -prices[i])`，即要么之前买入保持不变，要么当天买入；强制空仓状态依然是`sell[0][j] = 0`。

关于状态转移
```c
// 转移到持仓状态:
// 1. 已持仓: buy[i-1][j]
// 2. 未持仓: sell[i-1][j] - prices[i]
buy[i][j] = max(buy[i-1][j], sell[i-1][j] - prices[i]);
// 转移到空仓状态:
// 1. 已空仓: sell[i-1][j]
// 2. 未空仓: buy[i-1][j-1] + prices[i]
// 每次卖出计为交易次数增加，本次卖出必定是前一次持仓状态转移过来，因此是j-1，由至多j-1次交易转移到至多j次交易
sell[i][j] = max(sell[i-1][j], buy[i-1][j-1] + prices[i]);
```

整体代码如下(边界条件、特殊情形已处理)

```java
class Solution {
    public int maxProfit(int k, int[] prices) {
        // 数组长度为1的场景
        if (prices.length < 2) {
            return 0;
        }
        // k等效于不限交易次数场景
        if (prices.length / 2 <= k) {
            int max = 0;
            for (int i = 1; i < prices.length; i++) {
                max += Math.max(0, prices[i] - prices[i-1]);
            }
            return max;
        }

        int n = prices.length;

        // 定义动态规划数组
        // buy[i][j]: 至第i天结束、至多进行j次交易、手中持有股票的最大收益
        // sell[i][j]: 至第i天结束、至多进行j次交易、手中不持有股票的最大收益
        // 当完成卖出时，交易次数增加
        int[][] buy = new int[n][k+1];
        int[][] sell = new int[n][k+1];

        // 状态初始化:
        // 第0天持仓，收益只可能是-prices[0]
        // 第0天孔仓，收益只可能是0
        for (int j = 0; j <= k; j++) {
            buy[0][j] = -prices[0];
            sell[0][j] = 0;
        }

        for (int i = 1; i < n; i++) {
            // 任意某天，交易次数不超过0，持仓状态，此时最大收益前i天最低价买入
            buy[i][0] = Math.max(buy[i-1][0], -prices[i]);
            for (int j = 1; j <= k; j++) {
                // 转移到持仓状态:
                // 1. 已持仓: buy[i-1][j]
                // 2. 未持仓: sell[i-1][j] - prices[i]
                buy[i][j] = Math.max(buy[i-1][j], sell[i-1][j] - prices[i]);
                // 转移到空仓状态:
                // 1. 已空仓: sell[i-1][j]
                // 2. 未空仓: buy[i-1][j-1] + prices[i]
                // 每次卖出计为交易次数增加，本次卖出必定是前一次持仓状态转移过来，因此是j-1
                sell[i][j] = Math.max(sell[i-1][j], buy[i-1][j-1] + prices[i]);
            }
        }

        return sell[n-1][k];
    }
}
```
